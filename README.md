# Análisis de Ventas de un Minisúper - Proyecto Final Python

Este proyecto simula el análisis de ventas del mes de marzo en un minisúper familiar, "El Gallero S.A.", ubicado en el Mercado Central de Heredia. El objetivo es organizar los datos y aplicar técnicas básicas de análisis con Python.

## Estructura del proyecto

```
Proyecto-Final/
├── main.py              # Script principal con menú interactivo
├── utils.py             # Funciones auxiliares de análisis y gráficos
├── ventas_marzo.csv     # Archivo con los datos simulados de ventas
├── README.md            # Este documento
```

##  Requisitos
- Python 3.8 o superior
- pandas
- matplotlib

Puedes instalar los paquetes ejecutando:
```bash
pip install pandas matplotlib
```

## Cómo usar el proyecto

1. Clona este repositorio o descárgalo.
2. Asegúrate de que el archivo `ventas_marzo.csv` esté en la misma carpeta que `main.py`.
3. Ejecuta el programa:
```bash
python main.py
```
4. Usa el menú para explorar los reportes:
   - Resumen por día
   - Producto más vendido
   - Ingresos por producto y totales
   - Gráfico de ventas diarias

## Objetivo del proyecto

Aplicar conceptos de programación en Python utilizando estructuras como funciones, condicionales, ciclos, agrupaciones con pandas y visualización de datos.
